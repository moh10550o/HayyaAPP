# مكتبة الأذكار (islambook) ونصوص المناسبات

- `islambook-azkar.json`: الأذكار كما نُقلت من islambook.com/app/ar/azkr (النص بتشكيله + العدد + الفضل).
- `sources.py`: تخريج كل ذكر، وعلامات المراجعة: `weak` ضعيف، `disp` مختلف في ثبوته، `gen` دعاء عام غير مأثور بلفظه، `ref` نص للاطلاع، `athar` أثر موقوف.
  ما عليه علامة (عدا الأثر) يبقى في المكتبة لكنه **موقوف افتراضيًا** ويظهر سببه.
- `gen.py`: يولّد `src/islambook-lib.js`.
- `occasions.py` + `occgen.py`: نصوص المناسبات الهجرية؛ الآيات تُطابق حرفًا حرفًا مع نص المصحف (حزمة npm `quran-json`) ويُمنع التكرار.
- `qcheck.py`: يطابق الآيات الواردة في الأدعية القرآنية وأدعية الأنبياء مع نص المصحف.

المسارات داخل السكربتات مطلقة (بيئة البناء)؛ عدّلها قبل التشغيل على جهازك.
